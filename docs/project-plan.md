# 项目定位与范围

## 要解决的问题

个人学习和项目讨论发生在 ChatGPT 中，成果需要进入 Obsidian，后续还要能检索、补充、推进和回顾。手动搬运会丢失上下文，单靠对话也不便长期维护。

这个项目把“记录格式、AI 操作约定、MCP 接入、Windows 常驻、验收和迭代记录”整理成可复现的方案。

## 第一阶段的成果

1. 别人能看懂目录、记录类型与读写路径。
2. 当前 Windows 接入可以按文档复现。
3. 电脑重启后能够自动连接，并有明确的状态和排错入口。
4. 章节学习、项目文档、任务、回顾各有一个虚构示例与实际验收流程。
5. 每项改进有问题描述、提交记录和结果证据。

## 当前范围

- Markdown 模板与少量索引字段。
- ChatGPT 操作 Obsidian 的应用配置和提示词。
- Local REST API with MCP + Secure MCP Tunnel 的本机接入。
- Windows 登录启动、密钥保存、进程重试、日志和停止入口。
- 面向学习、项目和行动的工作流文档。

跨平台、一键创建 OpenAI 隧道、后台服务器部署和网页控制台作为后续候选需求。是否投入由真实使用问题决定。

## 仓库内容边界

仓库保存方案、代码、模板、虚构示例和脱敏问题记录。真实笔记在用户自己的库中维护。当前已建立公开仓库，首版保存方案、通用模板和脱敏实践记录。

把这个项目上传 GitHub，不会让本机服务在电脑关机后继续运行，也不会自动把个人笔记同步到云端。这两个需求需要单独设计。

## 推荐名称与简介

名称：`obsidian-ai-workflow`

简介：`A reproducible Obsidian + ChatGPT workflow for learning, projects, tasks and reviews, with Windows MCP tunnel setup.`

第一版定位为个人系统与接入方案的可复现记录。未来可以将稳定的部署部分整理成工具包，再按使用证据补充工作流案例。
