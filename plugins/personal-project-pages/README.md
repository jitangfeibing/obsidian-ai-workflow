# 项目页面助手 0.5.1

包含山林首页、随手记、收集箱内置分类菜单、自动模板转换与移动、项目/文档工作区、父子链接、章节创建、学习复习与归档恢复。

- 预编译插件：plugin/main.js、manifest.json、styles.css、assets/forest-banner.png。
- 可维护源码：src/；构建：node build.js。
- 安装与升级：仓库 setup/Install-System.ps1，见 docs/codex-migration.md。
- 内层根目录默认 personal-system-starter；同套模板和视图按此路径提供。

0.5.1 相对 0.5.0 增加自带分类下拉框，让新环境无需配置额外属性插件即可选择分类。其余沿用既有正文保护、原文件移动、父页校验和证据规则。
